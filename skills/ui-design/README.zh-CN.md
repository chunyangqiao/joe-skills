# UI Design

按设计原则，在用户指定的 Tailwind CSS v4 入口里设计 Design Token，并调整该项目基础组件目录中的 shadcn 组件。

## 内容

- 视觉层级、布局、排版、颜色、层次、图像和细节的指导。
- 无障碍、交互、暗色主题、动效和数据可视化的可选参考。
- 用户明确要求独立令牌包时，用于生成和校验该包的 CLI。

改动落在用户给出的入口文件和组件目录上。CLI 需要 Node.js 22 或更高版本，只使用内置模块。

从 [SKILL.md](SKILL.md) 开始。查看[设计系统命令](references/09-design-system.md)、[实现说明](references/10-implementation.md)和[审查指南](references/11-audit.md)。面向用户的交付内容使用用户当前使用的语言。
